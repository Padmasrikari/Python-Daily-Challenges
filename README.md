🚀 Getting Started
Prerequisites
Python 3.x installed [web:51]

Check your Python version:
python --version
or
python3 --version
Run a specific day

1.Clone the repository:

git clone https://github.com/Padmasrikari/Python-Daily-Challenges.git
cd Python-Daily-Challenges

2.Navigate to a day’s folder, for example Day 3:

cd Day_3

3.Run the solution:

python solution.py
 or
python3 solution.py
Some challenges may ask for input through the terminal; follow the prompts.
